# 📖 Overview

The **University Learning Management System (LMS)** is a Python-based console application that demonstrates the practical implementation of **Object-Oriented Programming** concepts. It replicates various university operations including student authentication, attendance management, marks calculation, hostel verification, fee management, and GPA calculation.

This project was built to strengthen programming fundamentals while simulating a real-world university environment.
